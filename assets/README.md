# 资源来源与版权说明

V0.1 不含外部图片、字体、音乐或音效文件，也未从网络抓取素材。

## 程序化美术

- 海洋背景、光束、气泡、海床、水草、鱼体、眼睛、鳍、纹样、关系标识、预警、HUD、按钮、教程、死亡和通关效果均由 `src/render/canvas-renderer.js` 使用 Canvas 2D 路径实时绘制。
- 5 种鱼纹样、玩家配色和所有动效参数为本项目原创代码配置。
- 界面使用运行环境系统字体栈和 Unicode 基础符号，不分发第三方字体文件。

## 程序化音频

- `src/audio/audio-manager.js` 使用 WebAudio 振荡器和包络实时合成吃草、吃鱼、同级弹开、危险预警、升级、死亡、通关、点击及低音环境声。
- 频率、时长、波形和增益表为本项目原创参数，不采样、改编或嵌入任何第三方录音。
- 只有用户手势解锁后才启动音频。WebAudio、系统音频或震动不可用时静默降级，不阻塞玩法。

## 后续资源管理

若后续加入外部资源，必须在此记录文件路径、作者/来源、许可证、允许的使用范围和必要署名；来源不明或授权不覆盖微信小游戏发布的资源不得进入发布包。
