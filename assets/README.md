# 资源来源与版权说明

V0.1 不含外部图片、字体、音乐或音效文件，也未从网络抓取素材。

## 程序化美术

- 海洋背景、光束、气泡、海床、水草、鱼体、眼睛、鳍、纹样、危险鱼红色闪烁轮廓、边缘预警、图鉴、HUD、按钮、教程、死亡和通关效果均由 `src/render/canvas-renderer.js` 使用 Canvas 2D 路径实时绘制。
- Lv.1–Lv.10 各有一套固定且唯一的原创程序化鱼素材；每套以颜色、主体轮廓、鳍尾和纹样组合区分，不使用外部图片。鱼体仍按统一等级尺寸公式逐级增大，玩家与同级野生鱼使用同一套素材。
- 实战鱼身旁不绘制等级、“可吃”或“同级”标记；只为高于玩家等级的 active 危险鱼绘制红色闪烁轮廓，pending 危险鱼继续使用屏幕边缘预警。等级数字保留在 HUD、升级反馈、结算和图鉴中；图鉴以 `5×2` 卡片展示十级名称、固定素材和相对体型。吞食吸入动画复用猎物原等级的颜色、轮廓、鳍尾和纹样。
- 界面使用运行环境系统字体栈和 Unicode 基础符号，不分发第三方字体文件。

## 程序化音频

- `src/audio/audio-manager.js` 使用 WebAudio 振荡器和包络实时合成吃草、吃鱼、同级弹开、危险预警、升级、死亡、通关、点击及低音环境声。
- 频率、时长、波形和增益表为本项目原创参数，不采样、改编或嵌入任何第三方录音。
- 只有用户手势解锁后才启动音频。WebAudio、系统音频或震动不可用时静默降级，不阻塞玩法。
